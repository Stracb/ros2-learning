### 讲解方式要求

1. **涉及 Linux 命令时，说明这条命令在干什么** —— 不要默认用户看得懂 `sed` / `grep` / `for` 循环
2. **讲 ROS 概念时，先讲"它解决什么问题"，再讲怎么用**
3. 用户说"不懂"时，换个说法重讲，不要重复原话
4. 不要一次抛出大量命令，**分步骤给，每步说清预期结果**
5. 用户会主动说"这些步骤是干嘛的"——**主动解释目的**，不要只给命令

## 六、已知的坑（勿重复踩）

| # | 坑 | 真相 |
|---|---|---|
| 1 | ROS 2 装法 | **2025 年后改用 `ros2-apt-source` 包**。网上 `apt-key add` 的老教程已失效 |
| 2 | `apt` 慢到 12.8 kB/s | **不是镜像慢**，是 `security.ubuntu.com` 超时重试拖累。改成国内镜像后变 4,643 kB/s |
| 3 | `grep -r` 找不到 `ros2.sources` | 它是**符号链接**，`grep -r` 默认不跟随，要用 `-R` 或 `cat` |
| 4 | Gazebo 界面频闪 | **Ogre2 与 VMware SVGA3D 不兼容**（与 3D 加速是否开启无关），换 `ogre` 引擎 |
| 5 | 虚拟机不能建在 `E:\VMware\` | 那是**程序安装目录**，权限受限（Everyone 只有 ReadAndExecute）|
| 6 | 快照占空间巨大 | 勾了「拍摄虚拟机内存」，每个快照 12 GB。**取消勾选** |
| 7 | 宿主机 HTTPS 不可用 | 沙箱进程报 `schannel: SEC_E_NO_CREDENTIALS`，只有明文 HTTP 可用（**仅影响助手，不影响用户**）|
