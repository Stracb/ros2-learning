## 第 0 步：准备工作

### 0.1 下载 Ubuntu 24.04 LTS 镜像

**目标版本：Ubuntu 24.04.5 (Noble Numbat)** —— 2026-09-08 发布，当前最新的 24.04 点版本。

| 项 | 值 |
|---|---|
| 文件名 | `ubuntu-24.04.5-desktop-amd64.iso` |
| 大小 | 5.9 GB |
| 官方 SHA256 | `63bed7c60c252d5563742b19204ff228ef9f7f10ac0a060159897ab423b6c398` |

**建议保存路径：`E:\ISO\ubuntu-24.04.5-desktop-amd64.iso`**（或任意位置，建虚拟机时能选到即可）

下载来源（任选其一，均支持 HTTPS）：

| 来源 | 直链 |
|---|---|
| 中科大 USTC | <https://mirrors.ustc.edu.cn/ubuntu-releases/24.04/ubuntu-24.04.5-desktop-amd64.iso> |
| 清华 TUNA | <https://mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/24.04/ubuntu-24.04.5-desktop-amd64.iso> |
| 阿里云 | <https://mirrors.aliyun.com/ubuntu-releases/24.04/ubuntu-24.04.5-desktop-amd64.iso> |
| 官方 | <https://releases.ubuntu.com/24.04/ubuntu-24.04.5-desktop-amd64.iso> |

> **镜像实测速度**（2026-09-11 本机测）：中科大 11.5 MB/s ＞ 北外 10.6 ＞ 清华 5.2 ＞ 官方 4.2。
> 阿里云和南大当时无响应。**优先用中科大。**

#### 校验完整性（必做）

```powershell
Get-FileHash "E:\ISO\ubuntu-24.04.5-desktop-amd64.iso" -Algorithm SHA256
```

输出必须与上表 SHA256 **逐字符一致**。不一致 = 文件损坏，需重新下载。

> **浏览器下载**最省事：复制上面的直链到浏览器地址栏即可。约 6 GB，中科大镜像通常 10 分钟内下完。
> 注意：浏览器**不支持断点续传**，中途断了要从头开始。要续传请用 IDM / 迅雷，或命令行 `curl -C -`。


### 0.2 确认宿主机资源（已实测）

| 资源 | 实测值 | 计划分配 | 结论 |
|---|---|---|---|
| CPU | Intel Core **i7-14650HX**（24 逻辑处理器）| 8 vCPU | ✅ 充足 |
| 内存 | **31.8 GB** | 12 GB | ✅ 充足 |
| E 盘可用空间 | **278 GB** | 虚拟机 80 GB | ✅ 充足 |
| VMware Workstation | 17.6.3，安装于 `E:\VMware\` | — | ✅ 含 `vmrun.exe` / `vmware-vdiskmanager.exe` |

> 参考：旧虚拟机只分了 4 vCPU / 4 GB 内存。宿主机 24 逻辑处理器、31.8 GB 内存，
> 却有 3/4 的算力和 7/8 的内存闲置着 —— 这就是旧环境跑不动仿真的根本原因。

## 第 1 步：创建虚拟机

打开 VMware Workstation 17.6.3：

### 1.1 新建向导

1. **文件 → 新建虚拟机 → 自定义（高级）→ 下一步**
2. 硬件兼容性：保持默认（Workstation 17.x）
3. **稍后安装操作系统**（关键！不要选 ISO，否则会走简易安装，参数不对）
4. 客户机操作系统：**Linux** → 版本 **Ubuntu 64 位**
5. 虚拟机名称：`Ubuntu-24.04-ROS2`
   位置：`E:\Ubuntu-24.04-ROS2`
6. 处理器配置：**处理器数量 2 × 每个处理器内核数 4 = 8 vCPU**
7. 内存：**12288 MB**（12 GB）
8. 网络类型：**NAT**
9. I/O 控制器类型：**NVMe**（性能优于 LSI Logic）
10. 磁盘类型：**NVMe**
11. 磁盘容量：**80 GB**
    - 建议选「将虚拟磁盘拆分成多个文件」（便于迁移和备份）
12. 完成

### 1.2 调整显示设置（关键，否则仿真跑不动）

虚拟机设置 → **显示**：

- ✅ 勾选 **加速 3D 图形**
- 图形内存：拉到最大（通常 8 GB）

### 1.3 挂载 ISO

虚拟机设置 → **CD/DVD (SATA)** → 使用 ISO 映像文件 → 选择下载的 `ubuntu-24.04.x-desktop-amd64.iso`
并勾选「启动时连接」。

### 1.4 待确认的 .vmx 关键参数

创建完成后，`E:\Ubuntu-24.04-ROS2\*.vmx` 中应包含：

```ini
memsize = "12288"
numvcpus = "8"
mks.enable3d = "TRUE"
svga.graphicsMemoryKB = "8388608"
```

> 对照你旧虚拟机的 `E:\Ubuntu-22.04.5\Ubuntu 64 位.vmx`：
> 旧配置是 `memsize = "4096"`、`numvcpus = "4"`、`svga.graphicsMemoryKB = "2097152"`（2 GB 显存）。
> 新配置在内存上是 3 倍，显存上是 4 倍。

## 第 2 步：安装 Ubuntu 24.04

1. 开启虚拟机，进入 Ubuntu 安装界面
2. 语言选 **English**（强烈建议！中文界面会让终端输出、报错信息路径出现乱码，且几乎所有教程截图都是英文）
   > 中文输入法后面单独装，不要用中文系统语言
3. 选择 **Install Ubuntu**
4. 键盘布局：English (US)
5. 网络：保持连接
6. 安装类型：**Normal installation**
   - ✅ 勾选 **Install third-party software for graphics and Wi-Fi hardware**
     （这一项对虚拟机 3D 驱动有帮助）
7. 安装类型：**Erase disk and install Ubuntu**（虚拟磁盘，无风险）
8. 时区：Shanghai
9. 用户名/密码：**务必记住**。建议用户名用英文小写，如 `ros`
10. 等待安装完成 → 重启

>  重启时若提示 "Please remove the installation medium"，直接回车即可。

## 第 3 步：安装 VMware Tools 与基础工具

进入桌面后打开终端（`Ctrl + Alt + T`）：

```bash
# 3.1 更新系统
sudo apt update && sudo apt upgrade -y

# 3.2 VMware Tools（剪贴板共享、分辨率自适应、共享文件夹）
sudo apt install -y open-vm-tools-desktop
# 安装后重启生效
sudo reboot
```

重启后继续：

```bash
# 3.3 开发基础工具
sudo apt install -y build-essential cmake git curl wget vim \
    python3-pip python3-venv net-tools tree htop

# 3.4 图形诊断工具（第 4 步要用）
sudo apt install -y mesa-utils

# 3.5 推荐：多标签终端
sudo apt install -y terminator
```

### 配置 git（求职要用 GitHub）

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

## 第 4 步：验证 3D 加速（关键）

**这一步必须做。** 如果 3D 加速没生效，RViz 和 Gazebo 会退化成 CPU 软件渲染，卡到无法使用。

```bash
glxinfo -B | grep -E "OpenGL renderer|OpenGL version|OpenGL core"
```

**判断标准：**

| 输出 | 含义 | 处理 |
|---|---|---|
| `OpenGL renderer string: SVGA3D; ...` | ✅ 硬件加速正常 | 继续 |
| `OpenGL renderer string: llvmpipe (...)` | ❌ 软件渲染 | 见下方排查 |
| `OpenGL version string: 4.3 ...` | ✅ 版本足够（Gazebo 需 ≥ 3.3） | 继续 |

**如果显示 llvmpipe：**

1. 确认虚拟机已关机，检查设置 → 显示 → 勾选「加速 3D 图形」
2. 确认 `open-vm-tools-desktop` 已安装并重启过
3. 重启虚拟机后再测
4. 仍然不行 → 在 VMware 设置里把「图形内存」调小一档再试（个别驱动对超大显存处理异常）

> 记录：**你的 3D 加速验证结果 = ___________（填写）**

## 第 5 步：配置国内镜像源

国内直连官方源很慢。切换到清华 TUNA 镜像（有 ROS 2 专属镜像，同步频率高）。

### 5.1 Ubuntu 系统源

打开「软件和更新」(Software & Updates) → Ubuntu Software → Download from → 选择 `mirrors.tuna.tsinghua.edu.cn`
或者直接编辑：

```bash
sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak
sudo sed -i 's|http://archive.ubuntu.com/ubuntu|https://mirrors.tuna.tsinghua.edu.cn/ubuntu|g; s|http://security.ubuntu.com/ubuntu|https://mirrors.tuna.tsinghua.edu.cn/ubuntu|g' /etc/apt/sources.list.d/ubuntu.sources
sudo apt update
```

### 5.2 确认 noble-updates 已启用

Ubuntu 24.04 全新安装时 apt 源可能只包含 `noble` 基础套件，会导致后续装 ROS 2 时依赖找不到：

```bash
grep -A2 "^Suites:" /etc/apt/sources.list.d/ubuntu.sources
```

确保输出包含 `noble noble-updates noble-backports`。若缺失，手工补齐后 `sudo apt update`。

## 第 6 步：安装 ROS 2 Jazzy

>  **注意：ROS 2 官方安装方式在 2025 年已变更。**
> 网上大量教程还在用 `apt-key add` + `ros2.list` 的老方法，**那些方法已经失效**。
> 现行方法是安装 `ros2-apt-source` 配置包（当前版本 1.3.0）。

### 6.1 添加 ROS 2 仓库

```bash
sudo apt update && sudo apt install -y curl

export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F'"' '{print $4}')
echo "版本: ${ROS_APT_SOURCE_VERSION}"

curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"

sudo dpkg -i /tmp/ros2-apt-source.deb
```

### 6.2 切换到清华 ROS 2 镜像（可选但强烈建议）

```bash
# 先看源文件名究竟是什么
ls /etc/apt/sources.list.d/
```

找到 ROS 相关的源文件（Ubuntu 24.04 下通常是 `ros2.sources`，也可能叫 `ros2.list`）。

如果是 `.sources` 格式：

```bash
sudo cp /etc/apt/sources.list.d/ros2.sources /etc/apt/sources.list.d/ros2.sources.bak
sudo sed -i 's|packages.ros.org/ros2/ubuntu|mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu|g' /etc/apt/sources.list.d/ros2.sources
cat /etc/apt/sources.list.d/ros2.sources   # 确认 URI 已替换、Signed-By 行仍在
```

> 密钥由 `ros2-apt-source` 包安装到 `/usr/share/keyrings/`，替换 URI 不影响签名校验。

### 6.3 安装 ROS 2

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y ros-jazzy-desktop
```

`ros-jazzy-desktop` 约 2–3 GB，包含 RViz2、演示程序、rqt 等全部常用工具。

> 磁盘紧张时可改用 `ros-jazzy-ros-base`（精简版），但学习阶段**不建议**，你会缺 RViz2 和 demo。

### 6.4 配置环境变量（关键）

```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

验证：

```bash
echo $ROS_DISTRO        # 应输出 jazzy
which ros2              # 应输出 /opt/ros/jazzy/bin/ros2
ros2 doctor             # 检查环境健康度
```

### 6.5 测试基础通信

打开两个终端：

```bash
# 终端 1
ros2 run demo_nodes_cpp talker

# 终端 2
ros2 run demo_nodes_py listener
```

终端 1 每 0.5 秒发布一条 `Hello World: N`，终端 2 接收并打印。
**看到两边都在滚动，说明 ROS 2 安装成功。**

### 6.6 安装常用扩展包

```bash
sudo apt install -y ros-jazzy-turtlesim \
    ros-jazzy-rqt ros-jazzy-rqt-common-plugins \
    ros-jazzy-tf2-tools ros-jazzy-tf-transformations \
    ros-jazzy-xacro ros-jazzy-urdf-tutorial \
    python3-colcon-common-extensions \
    python3-rosdep2
```

初始化 rosdep：

```bash
sudo rosdep init
rosdep update
```

## 第 7 步：安装 Gazebo Harmonic

ROS 2 Jazzy 与 Gazebo Harmonic 是官方默认配对。**不要单独安装 Gazebo Classic**（已 EOL）。

```bash
sudo apt install -y ros-jazzy-ros-gz
```

这会自动安装 Gazebo Harmonic 及其 ROS 桥接（通过 gz vendor 包）。

### 验证

```bash
# 7.1 独立启动 Gazebo Harmonic
gz sim shapes.sdf
```

应弹出 Gazebo 窗口，显示若干几何体。左侧应能看到 `shapes` 世界。

```bash
# 关闭后测试 ROS 2 桥接
ros2 launch ros_gz_sim gz_sim.launch.py gz_args:="shapes.sdf"

# 另开终端，查看桥接出来的话题
ros2 topic list
gz topic -l
```

能看到 `/clock`、`/tf` 等话题即成功。

### 关于性能

虚拟机中的 3D 加速**够用但不是原生水平**。若 Gazebo 明显卡顿：

1. 降低 Gazebo 渲染设置：关闭阴影、关闭抗锯齿
2. 用 **server only 模式**跑（不开 GUI）：
   ```bash
   gz sim -s -r shapes.sdf
   ```
3. 在复杂场景下改用 `-s` 无头模式 + RViz2 观察
4. 终极方案：若确定长期深耕仿真，考虑双系统装 Ubuntu 原生，或改用 WSL2（GPU 直通更好）

## 附录 A：环境搭建阶段的常见报错

> **这里只收录"搭环境时"会遇到的问题。**
> **日常开发的报错**（编译、运行、话题、服务、参数、自定义接口…）
> 查 **`08-踩坑总集.md`（64 条，带「按报错原文查」索引）**。

| 报错 | 原因 | 解决 |
|---|---|---|
| `E: Unable to locate package ros-jazzy-desktop` | ROS 源没配好，或 `noble-updates` 未启用 | 重做第 6.1；检查 `sources.list.d/ros2.*` 的 `Suites`/`URIs` |
| `ros2: command not found` | 环境变量没加载 | `source /opt/ros/jazzy/setup.bash`；确认已写入 `~/.bashrc` |
| ROS 2 装完但 `ros2 doctor` 报某些包缺失 | 部分依赖来自 universe 仓库 | `sudo add-apt-repository universe && sudo apt update` |
| Gazebo 启动白屏 / 崩溃 / 极卡 | 3D 加速未生效，走了 llvmpipe | 回第 4 步排查；临时可用 `LIBGL_ALWAYS_SOFTWARE=1 gz sim -s shapes.sdf` |
| `[gz sim] Error: Unable to find mesh` | 模型库未下载 | `gz sim` 首次运行会自动下载模型，需联网；国内可设 `GZ_SIM_RESOURCE_PATH` 手动指定 |
| 虚拟机里时间不对 | VMware 时钟同步被关闭 | 你旧 VM 里是 `tools.syncTime = "FALSE"`，新 VM 建议设为 `TRUE`，或 `sudo apt install chrony` |
| 剪贴板无法互通 | 缺 open-vm-tools-desktop | `sudo apt install -y open-vm-tools-desktop && sudo reboot` |
| `colcon build` 极慢 | 工作空间放在共享文件夹 | 移到虚拟机内部的 `~/ros2_ws` |
| 磁盘满 | 80 GB 也可能被 Gazebo 模型和 bag 文件撑满 | `sudo apt autoremove`；`du -sh ~/.gz ~/.cache` 排查 |

## 附录 B：虚拟机日常使用建议

### 快照（强烈建议）

VMware 里：**虚拟机 → 快照 → 拍摄快照**。

**命名建议**：`<天数>-<做了什么>`，比如 `07-画正方形以及参数化`、`10-参数与launch巩固`。
（**当前实际存在的快照**见 `00-接续说明.md` 第 3.2 节。）

**什么时候拍**：每完成一个明确的小阶段之后；以及**做有风险的操作之前**
（升级系统、装陌生驱动、大改环境）。

> ⚠️ **拍摄时务必取消勾选「拍摄虚拟机内存」**（注意）——
> 本机内存 12 GB，**勾选后每个快照就多占 12 GB**；不勾选只要几百 MB。
> 代价仅仅是恢复后重新开机（约 20 秒）。
> 详见 `08-踩坑总集.md` 坑 7。

**快照能让你在 3 分钟内回滚，而不是重装 3 小时。**

### 资源分配原则

宿主机 32 GB 内存，虚拟机给 12 GB 是安全的。若同时开 Gazebo + 浏览器 + IDE，可临时提到 16 GB（虚拟机需关机）。**不要给到 24 GB 以上**，否则宿主机会开始换页，整体反而更慢。

### 共享文件夹（可选）

虚拟机设置 → 选项 → 共享文件夹 → 添加 `E:\ROS2`，勾选「总是启用」。
在虚拟机内路径为 `/mnt/hgfs/ROS2`。

**仅用于交换文档资料，不要把代码工作空间放这里。**

### 备份策略

- 代码：用 git 推送到 GitHub（这是求职的一部分，一举两得）
- 环境：靠快照
- 虚拟机整机：定期把 `E:\Ubuntu-24.04-ROS2` 目录复制一份到移动硬盘
