### 常备参考：一个节点只有 3 块

**（这是第 3 天补的核心结构图，反复会用到，保留在这里）**

| 块 | 名称 | 什么时候跑 | 干什么 |
|---|---|---|---|
| **1-A** | `__init__` | 创建对象时，**一次** | **准备**：起名字、建发布者/订阅者/服务、建定时器 |
| **1-B** | 回调函数 | 每次触发，**反复** | **干活**：造消息、填内容、发出去 / 读消息 / 填 response |
| **2** | `main()` | 启动时，**一次** | 开机 → 造对象 → spin → 清理 |

**调用时序：**

```
main() → rclpy.init() → node = XxxNode() → 【__init__ 执行：准备】
      → rclpy.spin(node) → 定时器响 / 消息到达 / 服务被调用 → 调回调 → 循环
```

**类比：开店**
- `__init__` = 开店准备（挂招牌、装设备、设闹钟）
- 回调函数 = 营业接待（有客人/有订单就处理一次）
- `main()` = 开店流程（开机→造店→运转→打烊）

## 六、关于参数化的重要认知（用户问过）

**当前状态**：`draw_circle.py` 里的参数是**硬编码**的 —— 改行为必须改代码。

```python
msg.linear.x = 2.0      # 硬编码
msg.angular.z = 1.0     # 硬编码
```

**未来的正确做法**：ROS 2 **参数机制** —— 参数放外部 YAML 文件，
运行时用 `-p 参数名:=值` 修改，**不用动代码**：

```python
self.declare_parameter('linear_speed', 2.0)
msg.linear.x = self.get_parameter('linear_speed').value
```

```bash
ros2 run my_turtle draw_circle --ros-args -p linear_speed:=1.0
```

**这是第 4 周的内容**，现在知道有这个方向即可。
