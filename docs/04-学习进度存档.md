### 常备参考：一个节点只有 3 块

**（这是第 3 天补的核心结构图，反复会用到，保留在这里）**

| 块 | 名称 | 什么时候跑 | 干什么 |
|---|---|---|---|
| **1-A** | `__init__` | 创建对象时，**一次** | **准备**：起名字、建发布者/订阅者/服务、建定时器 |
| **1-B** | 回调函数 | 每次触发，**反复** | **干活**：造消息、填内容、发出去 / 读消息 / 填 response |
| **2** | `main()` | 启动时，**一次** | 开机 → 造对象 → spin → 清理 |

**调用时序：**

```
main() → rclpy.init() → node = XxxNode() → 【__init__ 执行：准备】
      → rclpy.spin(node) → 定时器响 / 消息到达 / 服务被调用 → 调回调 → 循环
```

**类比：开店**
- `__init__` = 开店准备（挂招牌、装设备、设闹钟）
- 回调函数 = 营业接待（有客人/有订单就处理一次）
- `main()` = 开店流程（开机→造店→运转→打烊）

## 六、参数化：从"知道方向"到"已经落地"（第 10 天结清）

**第 6 天的状态**：`draw_circle.py` 里的速度是**硬编码**的，改行为必须改代码。
当时记的是"未来的正确做法是参数机制，这是第 4 周的内容"。

**第 10 天：这笔账结清了。** `draw_circle` 已完整参数化：

```python
# __init__ 里：先集中声明，再集中读取（只做一次）
self.declare_parameter('linear_speed', 6.0)
self.declare_parameter('angular_speed', 3.0)
self.linear_speed = self.get_parameter('linear_speed').value
self.angular_speed = self.get_parameter('angular_speed').value

# 回调里：直接用 self. 变量（反复用）
msg.linear.x = self.linear_speed
msg.angular.z = self.angular_speed
```

**三种改参数的写法（都验证过，别混）：**

| 场景 | 格式 | 例子 |
|---|---|---|
| 命令行 | `-p 名字:=值` | `ros2 run my_turtle draw_circle --ros-args -p linear_speed:=2.0` |
| YAML 文件 | `名字: 值`（冒号 + 空格）| `config/circle_params.yaml` |
| launch 文件 | `parameters=[...]` | 指向 YAML 文件，或用 Python 字典 `{'linear_speed': 2.0}` |

**正规做法（第 10 天新学，求职必看）**：不在 launch 里写死路径，而是**问 ROS 要**：

```python
import os
from ament_index_python.packages import get_package_share_directory

config_file = os.path.join(
    get_package_share_directory('my_turtle'),
    'config',
    'circle_params.yaml'
)
# ...parameters=[config_file],
```

配 `setup.py`：`('share/' + package_name + '/config', ['config/circle_params.yaml']),`

> **为什么重要**：`/home/pummy/...` 写死 → 换台电脑就崩。

## 十一、每次涉及 launch / 参数时的固定话术（第 10 天用户要求）

**当这次会话要写 launch 文件或参数文件时，先问这一句：**

> "这次走**快速版**（`parameters=['/绝对路径/xxx.yaml']`，setup.py 只注册 launch）

**理由**：用户原话 —— "请以后每次写的时候都请提醒我是否要进行改造。"
不要先给能跑的土办法、再让他返工；**一开始就问清楚，直接按选定版本写。**

1. 注册进 `setup.py` 的 `data_files`（否则 `ros2 launch` 找不到）
2. **改了 setup.py 就必须重编**：`colcon build --packages-select my_turtle --symlink-install`
