#### 常备参考：一个节点只有 3 块

**（这是第 3 天补的核心结构图，反复会用到，保留在这里）**

| 块 | 名称 | 什么时候跑 | 干什么 |
|---|---|---|---|
| **1-A** | `__init__` | 创建对象时，**一次** | **准备**：起名字、建发布者/订阅者/服务、建定时器 |
| **1-B** | 回调函数 | 每次触发，**反复** | **干活**：造消息、填内容、发出去 / 读消息 / 填 response |
| **2** | `main()` | 启动时，**一次** | 开机 → 造对象 → spin → 清理 |

**调用时序：**

```
main() → rclpy.init() → node = XxxNode() → 【__init__ 执行：准备】
      → rclpy.spin(node) → 定时器响 / 消息到达 / 服务被调用 → 调回调 → 循环
```

**类比：开店**
- `__init__` = 开店准备（挂招牌、装设备、设闹钟）
- 回调函数 = 营业接待（有客人/有订单就处理一次）
- `main()` = 开店流程（开机→造店→运转→打烊）

### 类比：URDF ≈ 前端代码（第 17 天用户自己提的）

> 用户说："**这不就是前端代码吗**" —— **完全正确，而且这个类比对以后很有用**：

> | 前端 | URDF / Xacro |

> | CSS | `<material>` / `<color>` |
> | React 组件 | `<xacro:macro>` |
