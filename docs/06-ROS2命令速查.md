# 📌 零、名字记不住？查这里 ⭐

> **这些都是"查"的，不是"背"的。** 忘了就翻这一节。

## A. 话题名 / 服务名 —— 谁定的、能不能改

| 名字 | 谁定的 | 能改吗 | 在哪写 |
|---|---|---|---|
| **`/turtle1/cmd_vel`** | **turtlesim 定的**（你用它就得服从）| ⚠️ 改了乌龟就不听 | `create_publisher` 第 2 参 |
| **`/turtle1/pose`** | **turtlesim 定的** | ⚠️ 同上 | `create_subscription` 第 2 参 |
| **你的服务名**（如 `movemove`）| **你自己起** | ✅ 随便改 | `create_service` 第 2 参 |
| 你的其他话题名 | **你自己起** | ✅ 随便改 | 第 2 参 |

**一句话：用别人的东西→服从别人的名字；自己提供的东西→自己起名。**

## B. `create_xxx` 的参数顺序 ⭐

**记住一条规则：带引号的 = 名字，不带引号的 = 类型。**

| 方法 | 第 1 个 | 第 2 个 | 第 3 个 | 第 4 个 |
|---|---|---|---|---|
| `create_publisher` | **类型**（不带引号）| **名字**（带引号）| 队列长度 | — |
| `create_subscription` | **类型** | **名字** | **回调函数** | 队列长度 |
| `create_service` | **类型** | **名字** | **回调函数** | — |
| `create_timer` | **间隔秒数** | **回调函数** | — | — |

**具体例子（照抄改值即可）：**

```python
# 发布者
self.publisher_ = self.create_publisher(Twist, '/turtle1/cmd_vel', 10)

# 订阅者
self.sub_ = self.create_subscription(Pose, '/turtle1/pose', self.read_pose, 10)

# 服务端
self.srv_ = self.create_service(SetBool, 'movemove', self.operation)

# 定时器
self.timer_ = self.create_timer(0.1, self.send_spd)
```

> ⚠️ **回调函数名不加括号！** `self.read_pose` 不是 `self.read_pose()`

## C. 常见类型的字段

| 类型 | 字段 | 怎么用 |
|---|---|---|
| `geometry_msgs/msg/Twist` | `linear.x` `linear.y` `linear.z`<br>`angular.x` `angular.y` `angular.z` | 发速度：`msg.linear.x = 2.0` |
| `turtlesim/msg/Pose` | `x` `y` `theta`<br>`linear_velocity` `angular_velocity` | 读位置：`msg.x` |
| `std_srvs/srv/SetBool` | 请求：`data`<br>响应：`success` `message` | `request.data`<br>`response.success = True` |
| `std_srvs/srv/Trigger` | 请求：（空）<br>响应：`success` `message` | `response.message = '...'` |

**查任何类型的方法：**
```bash
ros2 interface show <完整类型名>
```

## D. import 语句速查

| 要用的东西 | import 语句 |
|---|---|
| Node 类 | `from rclpy.node import Node` |
| Twist 消息 | `from geometry_msgs.msg import Twist` |
| Pose 消息（乌龟的）| `from turtlesim.msg import Pose` |
| SetBool 服务 | `from std_srvs.srv import SetBool` |
| Trigger 服务 | `from std_srvs.srv import Trigger` |
| Empty 服务 | `from std_srvs.srv import Empty` |

> **规律：消息用 `.msg`，服务用 `.srv`。**
> `from 包名.msg import 消息名`
> `from 包名.srv import 服务名`


**需要别的依赖时，后面还可以手动往 `package.xml` 里加。**

## 第 3 步：写代码（每个新节点）

**在 VS Code 里，右键【内层】`my_turtle/` → New File → 输入 `节点名.py`**

⚠️ **必须放内层**，放外层的话 import 不到。

**代码骨架参考** `05-写节点清单.md` 第一部分。

---

## 第 4 步：注册入口 + 资源

### ① 注册程序入口（每个新节点）

**改 `setup.py` 的 `entry_points`：**

```python
    entry_points={
        'console_scripts': [
            'draw_circle = my_turtle.draw_circle:main',
            'draw_square = my_turtle.draw_square:main',      # ← 新增
        ],
    },
```

**格式：`'程序名 = 模块名.文件名:main'`**

| 部分 | 是什么 |
|---|---|
| 等号左边 | **程序名**（`ros2 run` 时用的，自己取）|
| `my_turtle` | **内层模块名** |
| `.draw_square` | **文件名**（不带 `.py`）|
| `:main` | 函数名（固定）|

### ② 注册资源文件（有 config/launch 文件时）

**改 `setup.py` 的 `data_files`：**

```python
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
        ('share/' + package_name + '/config', ['config/square_params.yaml']),   # ← 新增
    ],
```

**作用**：把 `config/` 里的文件也安装到 `install/<包名>/share/<包名>/config/`。

> **不做这一步的后果**：文件只在 `src/` 里，launch 文件找不到它，别人装了你的包也没有。

## 第 5 步：编译

```bash
cd ~/ros2_ws                     # ⚠️ 必须在工作空间【根目录】
colcon build --symlink-install
```

**预期输出**：`Summary: 1 package finished`

### 什么时候要重编 ⭐

| 改了什么 | 重编？ |
|---|---|
| **已注册文件的【内容】**（`.py`、launch、config 都算）| ❌ **不用** |
| **新增文件**并注册到 `setup.py` | ✅ **要** |
| **`setup.py` 本身**（entry_points / data_files）| ✅ **要** |
| `package.xml` | ✅ 要 |
| **不确定** | ✅ **重编，几秒钟的事** |

**一句话：改【内容】不用重编；改【结构】要重编。**

> **为什么？** `--symlink-install` 让"已存在的文件"用**符号链接**指向源码 ——
> 所以你改源码内容，链接那边立刻就是新的。
> **但"新增文件"需要建立新的链接 → 必须重编。**
>
> **实测验证**（第 7 天）：改了 `square_demo.launch.py` 的**内容**（加 `parameters=`），
> **没重编直接跑，生效了** ✅

### 常用编译选项

| 选项 | 作用 |
|---|---|
| `--symlink-install` | 符号链接代替复制（**Python 包必加**）|
| `--packages-select <包名>` | 只编译指定的包 |
| `--cmake-clean-cache` | 清了重编（疑难杂症时用）|

# 一、命令的通用结构 ⭐

**ROS 2 的命令几乎都是这个形状：**

```
ros2  <类别>  <动作>  [参数...]
       └─┬─┘  └─┬─┘
     操作什么   怎么操作
```

**举例：**

| 命令 | 类别 | 动作 |
|---|---|---|
| `ros2 node list` | node（节点）| list（列出）|
| `ros2 topic echo /turtle1/pose` | topic（话题）| echo（打印内容）|
| `ros2 service call ...` | service（服务）| call（调用）|
| `ros2 pkg executables turtlesim` | pkg（包）| executables（列出程序）|

**记住这个结构，你就能"猜"出命令。**

> **忘了有什么动作？** 只敲类别，它会列出所有可选动作：
> ```bash
> ros2 topic          # 回车，列出 topic 下所有动作
> ros2 node --help    # 看详细帮助
> ```

# 三、查看类命令（探索和排错）

## 节点 (Node)

```bash
ros2 node list                  # 列出所有正在运行的节点
ros2 node info /节点名           # 看这个节点的详细接口
```

**`ros2 node info` 会显示：** Subscribers / Publishers / Service Servers / Action Servers

## 话题 (Topic)

```bash
ros2 topic list                 # 列出所有话题
ros2 topic list -t              # 连带显示消息类型
ros2 topic echo /话题名          # 打印话题上的数据（会一直刷）
ros2 topic echo /话题名 --once   # 只打印一条
ros2 topic hz /话题名            # 测发布频率
ros2 topic info /话题名          # 谁在发、谁在收
ros2 topic pub /话题名 类型 "内容"  # 手动往话题发消息
```

**`ros2 topic pub` 示例：**

```bash
ros2 topic pub -r 10 /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0}}"
```

| 部分 | 含义 |
|---|---|
| `-r 10` | 每秒发 10 次（不加的话默认每秒 1 次）|
| `--once` | 只发一次就退出 |

## 服务 (Service)

### 查看

```bash
ros2 service list               # 列出所有服务
ros2 service list -t            # 连带显示服务类型
ros2 service type /服务名        # 查某个服务是什么类型
ros2 service list | grep 关键词   # 筛选（找自己的服务）
```

### 查有哪些服务类型可用 ⭐

```bash
ros2 interface list | grep "/srv/"        # 列出所有服务类型
ros2 interface show std_srvs/srv/SetBool  # 看某个类型长什么样
```

### 调用服务

```bash
ros2 service call <服务名> <服务类型> "<请求内容>"
         └──┬──┘ └──┬──┘ └───┬───┘ └────┬────┘
          命令   调用   哪个服务   它的类型    请求内容
```

| 类型 | 请求内容怎么写 |
|---|---|
| `std_srvs/srv/Empty`（请求是空的）| **不用写**，命令到此结束 |
| `std_srvs/srv/SetBool` | `"{data: true}"` 或 `"{data: false}"` |
| `std_srvs/srv/Trigger`（请求是空的）| **不用写** |
| `turtlesim/srv/Spawn` | `"{x: 8.0, y: 8.0, theta: 0.0, name: 'xx'}"` |

> ⚠️ **命令行里的布尔值写小写 `true` / `false`**（YAML 写法），
> **Python 代码里写大写 `True` / `False`**。

### 常用服务调用实例

```bash
# 清屏（Empty 类型 —— 不需要请求内容）
ros2 service call /clear std_srvs/srv/Empty

# 生成新乌龟
ros2 service call /spawn turtlesim/srv/Spawn "{x: 8.0, y: 8.0, theta: 0.0, name: 'myturtle'}"

# 乌龟瞬移
ros2 service call /turtle1/teleport_absolute turtlesim/srv/TeleportAbsolute "{x: 2.0, y: 2.0, theta: 0.0}"

# 调用自己写的服务（第 5 天的 turtle_control）
ros2 service call /movemove std_srvs/srv/SetBool "{data: true}"    # 让乌龟走
ros2 service call /movemove std_srvs/srv/SetBool "{data: false}"   # 让乌龟停

# 调用自己写的服务（第 4 天的 greeter）
ros2 service call /say_hello std_srvs/srv/Trigger
```

### ⭐ 完整实战流程（调用自己写的服务）

```bash
# ① 虚拟机桌面终端：启动乌龟窗口
ros2 run turtlesim turtlesim_node

# ② VS Code 终端：启动你的节点
ros2 run my_turtle turtle_control

# ③ 再开一个终端：确认服务注册了
ros2 service list | grep movemove
# 预期：/movemove

# ④ 调用服务
ros2 service call /movemove std_srvs/srv/SetBool "{data: true}"
# 预期：response: ... success=True, message='...'
#       乌龟开始走

# ⑤ 反向调用
ros2 service call /movemove std_srvs/srv/SetBool "{data: false}"
# 预期：乌龟停下
```

### 三个标准服务类型速查

| 类型 | `---` 上面（请求）| `---` 下面（响应）| 用在 |
|---|---|---|---|
| `std_srvs/srv/Empty` | （空）| （空）| 只要触发，不要参数不要结果 |
| `std_srvs/srv/Trigger` | （空）| `bool success`<br>`string message` | 触发 + 要结果 |
| `std_srvs/srv/SetBool` | `bool data` | `bool success`<br>`string message` | 设置一个开关 |

## 包 (Package)

### 创建包 ⭐

```bash
ros2 pkg create --build-type ament_python <包名> --dependencies <依赖1> <依赖2>
```

| 部分 | 含义 |
|---|---|
| `ros2 pkg create` | 创建一个新包 |
| `--build-type ament_python` | 这是 **Python 包**（C++ 包用 `ament_cmake`）|
| `<包名>` | **包名**（小写+下划线）|
| `--dependencies` | 声明依赖的包（自动写进 `package.xml`）|

**实例：**

```bash
# 进到工作空间的 src 目录
cd ~/ros2_ws/src

# 创建 my_turtle 包，依赖 rclpy 和 geometry_msgs
ros2 pkg create --build-type ament_python my_turtle --dependencies rclpy geometry_msgs

# 如果需要服务类型，再加 std_srvs
ros2 pkg create --build-type ament_python my_pkg --dependencies rclpy std_srvs
```

**它会自动生成：**

```
<包名>/                      ← 外层：ROS 包
├── <包名>/                  ← 内层：Python 模块（.py 放这里）
│   └── __init__.py
├── package.xml              ← 身份证（依赖已写进去）
├── setup.py                 ← 程序入口注册表
├── setup.cfg
├── resource/<包名>
└── test/
```

> ⚠️ **一个包可以放很多个 .py 程序**，不用为每个节点新建包。
> **什么时候建新包？** 当内容属于"另一类东西"时（如机器人模型、导航、接口定义）。

### 查看包

```bash
ros2 pkg list                   # 列出所有已安装的包
ros2 pkg list | wc -l           # 数一下有多少个
ros2 pkg prefix <包名>           # 这个包装在哪
ros2 pkg executables <包名>      # 这个包提供哪些可运行程序 ⭐
```

### 运行时操作（不改代码）

```bash

ros2 param get /节点名 参数名          # 读参数值

```

**实例（改乌龟窗口背景色）：**
```bash

ros2 param set /turtlesim background_r 255    # 改成红色，窗口立刻变红
```

### 启动时传参（不改代码）⭐

```bash
ros2 run <包名> <程序名> --ros-args -p 参数名:=值 -p 参数名2:=值2
```

| 部分 | 含义 |
|---|---|
| `--ros-args` | 后面是"ROS 参数"，不是程序自己的参数 |
| `-p` | **p**arameter，传一个参数 |
| `参数名:=值` | **注意是 `:=`（冒号等号）**，不是 `=` |

**实例：**
```bash
ros2 run my_turtle draw_square --ros-args -p side_length:=3.0 -p turn_speed:=0.15
```

### 从 YAML 文件加载参数

```bash
ros2 run <包名> <程序名> --ros-args --params-file <文件路径>
```

**实例：**
```bash
ros2 run my_turtle draw_square --ros-args --params-file ~/ros2_ws/install/my_turtle/share/my_turtle/config/square_params.yaml
```

### YAML 参数文件的格式 ⚠️

```yaml
/draw_square:              # ← 节点名（带 /）
  ros__parameters:         # ← 固定这么写，两个下划线！
    side_length: 3.0       # ← 参数名: 值
    forward_speed: 1.5
    turn_speed: 0.15
```

**三个容易错的点：**

| # | 要点 |
|---|---|
| 1 | 第一行是**节点名**，前面带 `/` |
| 2 | 第二行固定是 **`ros__parameters:`** —— **两个下划线** |
| 3 | 缩进用**空格**（2 个），**不能用 Tab** |

### 代码里怎么写（三个形状）

```python
# ① 声明参数（带默认值）—— 放 __init__ 里
self.declare_parameter('side_length', 1.5)

# ② 读取参数值 —— 放 __init__ 里
self.side_length = self.get_parameter('side_length').value

# ③ 使用
cmd.linear.x = self.forward_speed
```

> ⚠️ **ROS 2 规定：不先 `declare` 就不能 `get`**（会报 `not declared`）。
> **`declare` 同时决定了"用命令行的值还是默认值"** —— 命令行给了就覆盖默认。

# 四、编译运行流程（写代码必用）⭐

## 完整流程

```bash
# ① 进工作空间根目录（必须在根目录编译！）
cd ~/ros2_ws

# ② 编译
colcon build --symlink-install

source install/setup.bash

# ④ 运行
ros2 run my_turtle 程序名
```

## ⭐ 什么时候要重新编译

| 改了什么 | 重编？ |
|---|---|
| 已注册文件（`.py` / launch / config）的**内容** | ❌ **不用**（symlink 生效）|
| **新增文件**并注册到 `setup.py` | ✅ **要** |
| **`setup.py`（尤其 entry_points / data_files）** | ✅ **要** |
| `package.xml` | ✅ 要 |
| **不确定** | **✅ 重编，反正几秒钟** |

**一句话：改【内容】不用重编；改【结构】要重编。**

## 一次性配置（只需做一次）

```bash
# 把这两行写进 ~/.bashrc，以后新终端自动加载
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc
```

**作用**：每次打开终端自动设置 ROS 2 环境 + 你的工作空间。**不用手动 source 了。**

## 常用编译选项

| 选项 | 作用 |
|---|---|
| `--symlink-install` | 用符号链接代替复制文件（**Python 包必加**，省掉大量重编）|
| `--packages-select <包名>` | 只编译指定的包（包多了以后用）|
| `--cmake-clean-cache` | 清了重编（疑难杂症时用）|

# 六、三条相似的命令，对照记 ⭐

**它们结构一样，只是"发什么"不同：**

```bash
ros2 run          <包名> <程序名>
ros2 topic pub    <话题名> <消息类型> "<内容>"
ros2 service call <服务名> <服务类型> "<请求内容>"
```

| 命令 | 通信方式 | 特点 |
|---|---|---|
| `ros2 run` | 启动一个程序 | 启动后一直运行 |
| `ros2 topic pub` | **发布**（单向广播）| 一直发（除非 `--once`）|
| `ros2 service call` | **调用**（一问一答）| **发一次，等回复，结束** |

**记忆锚点：**

> **`pub` = 广播，发完就走**
> **`call` = 打电话，等对方回复**

| 类型 | 格式 | 例子 |

| 消息 | `包名/msg/消息名` | `geometry_msgs/msg/Twist` |

# 九、常见报错对照

## 命令类报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `Package 'xxx' not found` | 终端没 source 工作空间 | `source ~/ros2_ws/install/setup.bash` |
| `No executable found` | 程序名写错，或改了 setup.py 没重编 | 查 `ros2 pkg executables <包名>`；重编 |
| `the following arguments are required` | 命令参数少给了 | 看报错里的 `usage:` 那一行，看缺哪个 |
| `cannot open display` | 在 SSH 终端跑图形程序 | 改用虚拟机桌面终端 |

## Python 报错 ⭐

| 报错 | 原因 | 解决 |
|---|---|---|
| `AttributeError: 'Greeter' object has no attribute 'operation'` | **回调函数没缩进到类里**，或类里没这个方法 | 检查缩进；用 VS Code 折叠功能验证 |
| `AttributeError: ... has no attribute 'publisher_'` | **存的名字和用的名字不一致** | 存 `self.publisher_` 就得用 `self.publisher_` |
| `AttributeError: ... has no attribute 'messsage'` | **字段名拼写错误** | 用 VS Code 自动补全（打 `response.` 看列表）|
| **`UnboundLocalError: ... local variable 'xxx'`** | **忘了写 `self.`** | 引用自己类里方法/属性必须加 `self.` |
| `NameError: name 'xxx' is not defined` | 用了没导入的名字 | 检查文件开头的 import |
| `TypeError: ... takes N positional arguments` | 函数参数个数不对 | 对照形状模板数参数 |
| `IndentationError` | 缩进不对 | 同类方法左边对齐（缩进 4 格）|
| **`Assertion 'PyFloat_Check' failed` + `Aborted`** | **浮点字段赋了整数** | `2` → `2.0`，`0` → `0.0` |

## 没有报错但行为不对 ⭐

| 现象 | 可能原因 | 怎么查 |
|---|---|---|
| **服务调用卡住不返回** | 回调**忘了 `return response`** | 看回调最后一行 |
| **服务列表里找不到自己的服务** | 服务名写错（常见：把类型当名字）| `ros2 service list` 看实际叫什么 |
| **乌龟不动** | ① 初始状态就是"停"，**要先调用服务**<br>② `self.moving` 没被设成 True | `ros2 topic echo /turtle1/cmd_vel --once` 看 x 是几 |
| **改了代码没生效** | 改了结构但没重编 | `colcon build --symlink-install` |
| **`ros2 node list` 里没有我的节点** | 节点已崩溃退出 | 看终端有没有报错 |
